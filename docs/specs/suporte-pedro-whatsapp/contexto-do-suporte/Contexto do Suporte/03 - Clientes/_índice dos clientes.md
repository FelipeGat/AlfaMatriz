# Clientes

Uma pasta por cliente, com o nome `<nome curto> · <código>`:
- cliente do Gestor (manutenção e segurança eletrônica): `· gestor-<nº do cliente no Gestor>`;
- cliente dos sistemas (Matriz): `· matriz-<nº do cliente no Matriz>`;
- cliente das duas casas: os dois, como `Castanheiras · gestor-13 · matriz-5`.

O código é o que liga a conversa do WhatsApp à pasta: sem ele, o Pedro não acha o cliente. Dentro da pasta vão o
`contexto.md` (modelo em `_modelos/modelo de contexto de cliente.md`) e a pasta `atendimentos/`.
